# Working Style

- Before starting non-trivial work, resolve open questions with the AskUserQuestion tool until the requirements are clear.
- When no user is available to answer (unattended or background runs), proceed with reasonable defaults and state the assumptions you made.

# Commits

- Write commit titles in English. Bodies may be in Japanese.

# CLI

- Run Python through `uv` (`uv run`, `uvx`) instead of calling `python` directly.
